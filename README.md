# Refrigerator Controller

Control a refrigerator using C# MVC and Raspberry PI.

## System Settings

Users are able to change various system settings, including the temperature range and how long before the door 
alarm sounds.

## Temperature Logging

Temperature is logged and can be viewed via the UI or via API calls.

## API 

This application includes an API.  The API can be used to integrate with other systems that can process
JSON responses.

## Technical Notes

While this application uses C# MVC, it does not follow the Service, Repository, or Domain Driven Design Patterns 
as it was intended to be a project that was quickly built and to follow conventional MVC standards and best 
practices.
